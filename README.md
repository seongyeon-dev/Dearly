# Dearly 

나만의 취향을 기록하는 개인 위시리스트 및 구매 기록 관리 웹 서비스

## 프로젝트 소개

Dearly는 사고 싶은 상품을 저장하고, 구매를 고민하는 과정부터 구매 후 사용 경험까지 기록할 수 있는 개인 위시리스트 서비스입니다.

## Tech Stack

- Frontend: React, TypeScript, Vite, CSS Modules
- Backend: Java, Spring Boot, Spring Data JPA
- Database: MySQL
- API Communication: Axios
- Version Control: Git, GitHub

## Main Features

- 회원가입 및 로그인
- 위시리스트 등록·조회·수정·삭제
- 카테고리 및 구매 상태별 상품 관리
- 상품 관심도 설정
- 구매 후기 및 별점 작성
- 프로필 관리
