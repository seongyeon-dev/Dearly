# Dearly

나의 취향과 소비를 기록하는 Wishlist & Review 웹 서비스입니다.

## Project

관심 있는 상품을 위시리스트에 저장하고 구매한 상품과 소비 내역을
기록할 수 있는 개인 소비 관리 프로젝트입니다.

현재 프론트엔드부터 개발을 진행하고 있으며,
추후 Node.js 기반 백엔드와 MySQL 데이터베이스를 연동할 예정입니다.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router DOM
- Axios

### Backend
- Node.js
- Express

### Database
- MySQL
